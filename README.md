## Featured Projects

### [rest-shop](https://github.com/Zoe-life/rest-shop)
High-performance MERN e-commerce platform built with TypeScript. Features a dual-backend architecture with Cloudflare Workers handling edge proxying, a secure RESTful API, and MongoDB Atlas for data persistence. Designed with scalability and system resilience as primary constraints.
**Stack:** TypeScript, React.js, Node.js, Express.js, MongoDB, Cloudflare Workers

### [Mamawell](https://github.com/Zoe-life/Mamawell)
A secure, full-stack web application for expectant mothers. Provides pregnancy journey tracking, nutrition and exercise guidance, peer connection features, and a telemedicine consultation layer. Built with a strong emphasis on data security and healthcare compliance considerations.
**Stack:** TypeScript, REST API, full-stack web application

### [Waridi](https://github.com/Zoe-life/Waridi)
A comprehensive security testing toolkit targeting web applications and APIs. Exposes both a CLI interface for scripted workflows and a web dashboard for interactive use. Designed for security professionals, penetration testers, and DevSecOps practitioners who need a unified vulnerability assessment surface.
**Stack:** Python, CLI tooling, web dashboard, API security

### [Bubbble](https://github.com/Zoe-life/Bubbble)
A security tool that intercepts outbound links, analyses their legitimacy against known threat indicators, and wraps suspicious URLs in a safe inspection layer before the user proceeds. Addresses the growing attack surface introduced by link-based phishing and malware delivery.
**Stack:** Python

### [boldadventures](https://github.com/Zoe-life/boldadventures)
A full-stack platform connecting outdoor enthusiasts with guided biking and hiking experiences. Includes a complete booking system, integrated payment processing, and enterprise-grade security controls.
**Stack:** JavaScript, Node.js, REST API

### [curl-quest](https://github.com/Zoe-life/curl-quest)
A community platform that bridges the gap between clients with natural African hair and specialist natural hair care professionals. Built to serve a niche that is consistently underserved by mainstream beauty technology.
**Stack:** JavaScript

### [study-material-automator](https://github.com/Zoe-life/study-material-automator)
An automated pipeline that ingests PDF class notes and outputs structured study materials complete with diagrams and interactive illustrations. Reduces the manual effort involved in turning raw lecture content into usable revision resources.
**Stack:** Python
